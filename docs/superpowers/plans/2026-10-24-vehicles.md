# T9 Vehicles Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A crafted Tank (or car) item places a drawn, rideable vehicle that drives with WASD, aims with the mouse and fires the item's `infinite_craft:shoot` from its barrel, safely, in singleplayer and on a dedicated server.

**Architecture:** One `infinite_craft:vehicle` data component (Claude writes it, like `shoot`) and one `VehicleEntity` that extends `MobEntity` and rides on vanilla's ridden-mob hooks (`getControllingPassenger`, `getControlledMovementInput`, `tickControlled`, `getSaddledSpeed`), so movement and multiplayer sync are vanilla's horse/pig path. The entity stores the item stack that placed it (tracked data), so body, speed, color and weapon are known on both sides and saved with the world. Firing goes through a C2S payload into `ShootAbility`, with a muzzle position at the barrel tip.

**Tech Stack:** Minecraft 1.21.10, Fabric API, yarn mappings, Fabric game tests (`runGameTest`) and client game tests (`runClientGameTest`), Python 3 for `tools/textures/make_textures.py`.

**Spec:** `docs/superpowers/specs/2026-10-24-vehicles-design.md`

## Review Focus

1. **The rider's world interactions while seated.** Right-clicking a block, door or chest while riding should fire, not place the held block or open things. Tested in Task 4 (`fireKeyFiresInsteadOfUsingHeldItem`).
2. **A vehicle placed in a 1-block gap or under a low ceiling.** It shouldn't place inside blocks or suffocate. Placement checks space for the scaled box and returns `FAIL` otherwise; tested in Task 1 (`placementNeedsRoom`).
3. **Getting out next to walls or water.** The rider must land on a free, solid spot (vanilla `Dismounting.findRespawnPos`/`updatePassengerForDismount`), never inside a block. Tested in Task 2 (`dismountNeverSuffocates`).
4. **A vehicle item with only `vehicle` and no `shoot`.** Fire is a no-op, nothing crashes, and the tooltip says nothing about guns. Tested in Task 4 (`carWithoutGunFiresNothing`).
5. **World save/reload.** The stored item stack and its components survive `writeCustomData`/`readCustomData`. Tested in Task 1 (`vehicleSurvivesSaveAndLoad`, round-tripping through NBT).
